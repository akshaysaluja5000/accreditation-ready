OVERVIEW
Implement an event-driven points ledger that tracks all user activity across the platform and powers three things:

A staff-facing score and leaderboard (gamification / pilot competition)
A leadership dashboard showing engagement per staff member
A drill-down view for CEO/admin showing full activity breakdown
Core Rules
Points are awarded for correct answers only — incorrect answers earn nothing
Diagnostic completion earns no bonus — it is mandatory, not an achievement
Flashcard reviews earn points regardless of rating (Again/Hard/Good)
Final exam completion and first-attempt pass earn bonus points
Daily login bonus awarded once per day on first activity
All scoring calls must be non-blocking — never interrupt the learning flow
If the scoring API fails for any reason, fail silently, log to console only
Passing score is 75% across all modules — both hospital and ASC sides

STEP 1 — DATABASE
Run this SQL to create the two required tables.

-- Table 1: Points ledger
-- Every scoreable action writes one row here
-- Never delete rows — always sum to get current score

CREATE TABLE points_ledger (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id         UUID NOT NULL REFERENCES users(id),
  facility_id     UUID NOT NULL REFERENCES facilities(id),
  event_type      VARCHAR(50) NOT NULL CHECK (event_type IN (
                    'question_correct',
                    'flashcard_again',
                    'flashcard_hard',
                    'flashcard_good',
                    'daily_login',
                    'final_complete',
                    'final_passed_first_attempt'
                  )),
  points_awarded  INTEGER NOT NULL,
  module_id       UUID REFERENCES modules(id),
  question_id     UUID REFERENCES questions(id),
  metadata        JSONB DEFAULT '{}',
  created_at      TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Indexes for fast leaderboard and drill-down queries
CREATE INDEX idx_points_ledger_user_id     ON points_ledger(user_id);
CREATE INDEX idx_points_ledger_facility_id ON points_ledger(facility_id);
CREATE INDEX idx_points_ledger_created_at  ON points_ledger(created_at);
CREATE INDEX idx_points_ledger_event_type  ON points_ledger(event_type);


-- Table 2: Pilot config
-- Controls the date range for leaderboard competition
-- One row per facility per pilot

CREATE TABLE pilot_config (
  id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  facility_id  UUID NOT NULL REFERENCES facilities(id),
  pilot_name   VARCHAR(255),
  start_date   TIMESTAMP WITH TIME ZONE NOT NULL,
  end_date     TIMESTAMP WITH TIME ZONE NOT NULL,
  is_active    BOOLEAN DEFAULT true,
  created_at   TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
