TASK 2 — Compliance Checklist: Add Completion Logging (2 hours)
File: task2_compliance_checklist_log.js
═══════════════════════════════════════════════════════════

WHAT THIS ADDS:
  A "Log Completion" button on each of the 132 checklist items.
  When clicked, it saves a timestamped log entry so surveyors
  can see proof of compliance over time.

STEPS:

Step 2A — Run in Replit DATABASE CONSOLE:

  CREATE TABLE IF NOT EXISTS compliance_completion_log (
    id            SERIAL PRIMARY KEY,
    item_id       INTEGER NOT NULL,
    item_code     VARCHAR(30),
    item_name     TEXT,
    completed_by  VARCHAR(100),
    completed_at  TIMESTAMPTZ DEFAULT NOW(),
    notes         TEXT,
    facility_id   VARCHAR(50),
    module        VARCHAR(20) DEFAULT 'ASC'
  );

  ALTER TABLE compliance_checklist_items
    ADD COLUMN IF NOT EXISTS owner_role      VARCHAR(30)  DEFAULT 'administrator',
    ADD COLUMN IF NOT EXISTS last_completed  TIMESTAMPTZ  DEFAULT NULL,
    ADD COLUMN IF NOT EXISTS completed_by    VARCHAR(100) DEFAULT NULL,
    ADD COLUMN IF NOT EXISTS completion_count INTEGER     DEFAULT 0;

  NOTE: If your checklist table has a different name, find it with:
  SELECT table_name FROM information_schema.tables WHERE table_name LIKE '%checklist%';

Step 2B — Assign owner roles. Run in DATABASE CONSOLE:

  UPDATE compliance_checklist_items SET owner_role = 'facilities'
  WHERE volume IN (1,2,3,4,5);

  UPDATE compliance_checklist_items SET owner_role = 'nursing'
  WHERE volume = 6;

Step 2C — Add API routes from task2_compliance_checklist_log.js:
  - POST /api/compliance-checklist/:id/log-completion
  - GET  /api/compliance-checklist/:id/history
  - GET  /api/compliance-checklist/overdue

Step 2D — Add "Log Completion" button to each checklist item card
  in your React component. Show last_completed date below each item.
  Color code: Green = done, Orange = due soon, Red = overdue.
